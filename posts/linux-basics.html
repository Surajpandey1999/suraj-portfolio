Linux Basics Every Cloud Engineer Should Know

Essential commands, the file system layout, permissions, and processes — explained with diagrams, not just a wall of commands to memorize.

By Suraj Pandey•9 August 2026•5 min read

Why Linux Matters for Cloud Engineers

Almost every cloud server, container, and CI/CD pipeline runs on Linux. AWS EC2 instances, Docker containers, Kubernetes nodes — all Linux underneath. You cannot work seriously in cloud/DevOps without it.

The Linux File System Layout

Unlike Windows (C:\, D:\), Linux has a single unified tree starting at / (root) — everything branches from there.

Everything lives under one root tree — no separate drive letters like Windows.

Essential Commands

pwd     # show current directory ls -la   # list all files with details cd /path # change directory mkdir dir # create a folder cp a b   # copy file mv a b   # move / rename file rm file  # delete file cat file # print file contents grep text file  # search inside a file chmod 755 file # change permissions ps aux  # list running processes top     # live process monitor

Understanding File Permissions

Every file has permissions for three groups: the owner, the group, and others — each can have Read, Write, and Execute access.

Example: -rwxr-xr-- — owner can read/write/execute, group can read/execute, others can only read.

NumberPermissionMeaning
7rwxRead + Write + Execute
5r-xRead + Execute
4r--Read only
chmod 754 file  # owner=rwx, group=r-x, others=r--

Processes

Every running program is a process with a unique Process ID (PID). ps aux lists them, top shows them live, and kill PID stops one.

Conclusion

You don't need to memorize every command — you need to understand the file system structure, how permissions work, and how to inspect running processes. Everything else you'll pick up by doing.
